# JAIL HERO ADVENTURE GAME

## About the Project
Jail Hero Adventure Game is a browser-based adventure game developed using JavaScript and Phaser. The game provides an exciting experience where players control a hero, overcome obstacles, and progress through an adventurous environment.

## Features
- Interactive hero character
- Adventure-style gameplay
- Obstacles and challenges
- Character movement and animations
- Background environment
- Browser-based gameplay
- Sound and visual effects (as implemented)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Phaser 4
- Vite

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yashwanthrevu9/Jail-Hero-Adventure-Game.git
   ```

2. Open the project folder:
   ```bash
   cd Jail-Hero-Adventure-Game
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
